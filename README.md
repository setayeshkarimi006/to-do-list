# 📝 To-Do List — Persian Daily Planner

A simple, responsive, and user-friendly task management application built with **HTML, CSS, and Vanilla JavaScript**.

This project helps users organize their tasks into daily, weekly, and monthly categories, create custom folders, and track completed activities. It also uses the browser's `localStorage` to preserve tasks and folders across page reloads.

---

## ✨ Features

* 📅 **Persian Calendar:** Displays the current date using the Persian (Solar Hijri) calendar.
* 📌 **Task Categorization:** Organize tasks into daily, weekly, and monthly sections.
* 📂 **Custom Folders:** Create folders with custom names to organize tasks.
* ✅ **Task Completion:** Mark tasks as completed with an interactive checkbox.
* 💾 **Local Data Persistence:** Save tasks and folders in the browser using `localStorage`.
* 📱 **Responsive Design:** Adapt the interface to desktop, tablet, and mobile screen sizes.
* 🎨 **Modern Interface:** A dark-themed design with purple accents and a clean layout.
* ⚡ **Lightweight and Fast:** Built with native web technologies without requiring a JavaScript framework.

| Technology          | Purpose                                                               |

## 🚀 Getting Started

### Prerequisites

A modern web browser is all you need to run this application.

No Node.js, Vite, or additional package installation is required.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/setayeshkarimi006/to-do-list.git
   ```

2. Navigate to the project directory:

   ```bash
   cd to-do-list
   ```

3. Open `index.html` in your web browser.

   Alternatively, you can use the Live Server extension in Visual Studio Code for a convenient local development experience.

## 💾 Data Persistence

The application uses the browser's `localStorage` to store task and folder data.

This allows the data to remain available after refreshing or reopening the application in the same browser and origin.

**Note:** Data is stored locally in the browser. It is not synchronized across devices or browsers, and clearing the browser's site data may remove it.
